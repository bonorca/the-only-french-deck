## 卡片内容

- **正面只有发音**：先听，再回想这个词怎么拼、什么意思。听力和词汇一起练。
- **背面**：
  - **单词**：名词带冠词，用颜色标出阴阳性：蓝色是阳性，红色是阴性，紫色是阴阳同形。
  - **形容词**：用表格列出四种形式，左列阳性、右列阴性，上排单数、下排复数。阳性复数读音变了的（比如 normal → normaux），会标出读音 /nɔʁmo/。beau / bel 这类元音前的特殊形式也会注明。
  - **中文释义**：带词性，一个词有几个常用义项就列几个。
  - **例句**：每个词最多两句，法语句子下面是中文翻译。句子都是标准法语，尽量体现搭配、名词的阴阳性和词的不同义项，不放「c'est très bon」这种没有参考价值的句子。
  - **说明（cf.）**：部分词附有提醒，比如容易混淆的词、阴阳性陷阱、用法注意。
- **发音**：Google Chirp 3 HD 合成语音，巴黎口音。
  - 名词先读单词，再读带冠词的形式（cause → la cause）。
  - 形容词先读阳性，再读阴性（petit → petite）。
  - 词尾的 r 音专门加强过，听得更清楚。

## 下载与导入

1. 安装官方最新版 Anki
2. 到 [Releases 页面](https://github.com/chillibeaver/the-only-tcf-deck/releases/latest) 下载 `.apkg` 文件。
3. 在 Anki 里打开它，或者点「文件 → 导入」，就会出现「你唯一需要的TCF法语卡组」。
4. 想在多台设备上学，就登录 [AnkiWeb](https://ankiweb.net/) 同步。第一次同步要上传几千个发音文件，可能需要一段时间。

## 反馈问题

发现发音、释义、例句或者阴阳性数有错，或希望添加新的高频词汇, 欢迎反馈：

- 直接点击卡片最下方的`反馈这张卡`按钮。
- 也可以到 [Issues](https://github.com/chillibeaver/the-only-tcf-deck/issues) 新建。

## 更新卡组

有新版本时，下载新的 `.apkg` 直接导入就行。Anki 会认出是同一批卡，只更新内容，**你的学习进度不受影响**。
